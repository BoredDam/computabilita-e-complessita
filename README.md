# Computabilità e complessità

Questa repository è dedicata ai miei appunti del corso di **Computabilità e Complessità** dell'Università di Catania (Dipartimento di Matematica e Informatica).

## Risorse

Questi appunti sono basati sulle lezioni del 2025/26 del professore Domenico Cantone, ma anche sul libro di testo consigliato, ossia:

> N.J. Cutland. Computability: an introduction to recursive function theory, Cambridge University Press, Cambridge - UK, 1986.

<img src="https://assets.cambridge.org/97805212/94652/large_cover/9780521294652i.jpg" alt="N.J. Cutland. Computability: an introduction to recursive function theory, Cambridge University Press, Cambridge - UK, 1986." width="200">


### Importante!

Questi appunti non si pongono in alcun modo come alternativa valida ai materiali esposti a lezione, tantomeno alla frequenza stessa delle lezioni. Si invitano quindi gli studenti interessati, a seguire il corso, e ad affiancare ai propri appunti i suddetti materiali.
